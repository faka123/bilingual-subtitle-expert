# 双语字幕精确排版技能手册

## 一、技能定位

**目标**：把「校对好的完整双语内容」（DOCX）精确匹配到「带时间轴的中文字幕框架」（TXT）中，生成符合专业标准的 SRT 双语字幕文件。

**核心矛盾**：
- 校对文档语言自然流畅，但**没有时间轴、不考虑断句**。
- 时间轴文档断句符合视频节奏，但**可能缺少英文，或英文与校对文档不一致**。

**解决思路**：中文完全跟随时间轴，英文以校对文档为准、按中文行数重新分割。

---

## 二、输入文档规范

### 2.1 校对文档（DOCX）

**特征**：
- 完整的中英文段落对应，每段中文后紧跟对应英文。
- 段落之间用空行分隔。
- 保留原文所有语言细节（标点、特殊符号、专有名词、数字单位）。
- 语言自然流畅，未考虑时间限制。

**格式示例**：
```
中文段落1
英文段落1

中文段落2
英文段落2
```

**常见干扰项**：
- `{.mark}` 标记（Word 高亮残留），须忽略。
- 中英文被错误合并到同一行（如 `中文English`），须拆开。
- 英文中出现反斜杠转义（如 `\'`），须还原为 `'`。
- 英文中出现 `[~~by everyone~~]{.mark}` 之类的修订痕迹，取最终文字。
- 中文中有 `*`、`（住）`、`SW`、`gld` 等缩写或屏蔽字，**照抄不改**。

### 2.2 时间轴文档（TXT）

**特征**：
- 已分割的、带时间轴的中文字幕。
- 标准 SRT 格式：序号、时间轴、文本、空行。
- 断句基于视频节奏和口语停顿。

**格式示例**：
```
1
00:00:00,200 --> 00:00:02,200
中文文本1

2
00:00:02,233 --> 00:00:04,666
中文文本2
```

**常见干扰项**：
- 时间轴文档末尾可能自带一份英文（可能是机器翻译或旧版英文），**一律不采用**。
- 时间轴文档中可能有重复条目（如第8、9条完全相同），**照抄保留**。
- 时间轴文档中可能有异常时间轴（如第96条时间轴存在但文本为空），**照抄保留**。
- 时间轴文档中可能有错误时间轴顺序（如英文部分时间轴乱序），**中文部分照抄，英文部分跟随对应中文**。

## 三、核心处理规则（最高优先级）

### 3.1 第一原则：英文以校对文档为准

**这是最重要的规则。**

- 英文内容**必须**从校对文档（DOCX）提取。
- **绝对禁止**直接照搬时间轴文档（TXT）中自带的英文。
- 若 TXT 中的英文与 DOCX 不一致，**以 DOCX 为唯一标准**。
- TXT 中的英文仅作参考，不具权威性。

**典型错误案例**：
- TXT 自带英文：`Nearest San Paolo`（错误）
- DOCX 正确英文：`Recently, Sinpolo's`（正确）
- 处理结果：采用 `Recently Sinpolo's`

### 3.2 第二原则：中文完全保留

- 中文部分的**序号、时间轴、文本**完全按时间轴文档原样输出。
- 不修改中文文本，不调整中文断句，不合并或拆分中文条目。
- 中文中的标点、特殊符号、屏蔽字（`*`、`SW`、`gld`、`Z好`、`D场`）照抄。
- 中文中的重复条目、空条目、异常时间轴照抄保留。

### 3.3 第三原则：断句行数一致

- 中文有多少条，英文就有多少条。
- 英文条目数 = 中文条目数，**不多不少**。
- 每个英文条目与对应中文条目**一一对应**。
- 英文断句必须在该中文条目范围内完成，**绝不跨段**。

### 3.4 第四原则：时间轴复制

- 英文部分使用与对应中文行**完全相同**的时间轴。
- 不修改时间轴，不重新计算时间。
- 中文第 N 条的时间轴 = 英文第（N + 中文总条数）条的时间轴。

### 3.5 第五原则：序号续接

- 中文部分：使用时间轴文档的原始序号（1 到 N）。
- 英文部分：从中文部分的最大序号 + 1 开始连续编号（N+1 到 2N）。
- 总序号 1 到 2N 连续无缺、无重复。

### 3.6 第六原则：标点处理

- 按用户每次的具体要求执行。
- 常见要求：
  - **去掉标点**：去掉英文句末标点（句号、逗号、问号、感叹号），保留内部必要标点（如 `0.025/mg³` 中的小数点、`30/m²-100/m²` 中的连字符）。
  - **保留标点**：完全保留原文标点。
- 中文标点一般照抄不改。

## 四、处理流程（标准操作步骤）

### 步骤 1：解析时间轴文档

1. 提取所有中文条目，记录：序号、开始时间、结束时间、中文文本。
2. 统计中文条目总数 N。
3. 识别并忽略 TXT 末尾自带的英文部分（如果有）。

### 步骤 2：解析校对文档

1. 提取中英文段落对应关系。
2. 忽略 `{.mark}` 标记、修订痕迹。
3. 还原转义字符。
4. 建立「中文段落 → 英文段落」映射表。

### 步骤 3：匹配中文条目与校对段落

1. 按顺序或相似度，将时间轴文档的中文条目与校对文档的中文段落对应。
2. 当文本不完全相同时，使用文本相似度算法匹配最接近的段落（相似度阈值可设为 30%）。
3. 优先匹配关键词和核心内容，忽略口语化添加词（如「呢」「啊」）。
4. 确认匹配结果合理。

### 步骤 4：英文断句分配

1. 对每个中文条目，确定其对应的英文段落。
2. 将该英文段落分割为与中文条目数相同的行数。
3. 断点选择：
   - 优先在句子自然停顿处（标点符号后）。
   - 不拆分完整的英文短语或意群。
   - 确保每行语义完整、易于阅读。
   - 建议每行不超过 42 个字符。
4. 当多个中文条目对应一个英文段落时，合理分割，确保各部分语义完整。
5. 当一个中文条目对应多个英文句子时，可合并或按需分割。

### 步骤 5：生成输出

1. **中文部分**：完全按时间轴文档输出。
2. **英文部分**：按匹配结果重新排版输出。
3. 格式：
   ```
   序号
   开始时间 --> 结束时间
   文本
   （空行）
   ```
4. 序号连续，时间轴对应准确，行数匹配一致。

### 步骤 6：质量检查

**完整性检查**：
- 所有中文片段都有英文对应（或标记为未匹配）。
- 所有英文内容完整呈现。
- 没有遗漏的段落或句子。

**一致性检查**：
- 中英文序号连续无重复。
- 时间轴对应准确无误。
- 行数匹配完全一致。
- 无跨段现象。

**可读性检查**：
- 英文断句符合英语阅读习惯。
- 每行字幕在屏幕上易于阅读。
- 复杂句子已适当分割。

## 五、特殊情况处理

### 5.1 多对一匹配

**情景**：多个中文片段对应一个英文段落。

**处理**：将英文段落合理分割为多个部分，确保各部分语义完整。

### 5.2 缺少对应

**情景**：中文片段找不到合适的英文段落匹配。

**处理**：标记为「未匹配」，保留中文部分，英文部分留空或提供提示。

### 5.3 内容不一致

**情景**：时间轴中文与校对文档中文有差异。

**处理**：以时间轴文档为准，调整英文内容匹配中文长度和节奏。

### 5.4 复杂句子处理

**情景**：英文句子过长或复杂。

**处理**：在保持语义完整的前提下，按自然停顿点分割，确保每行字幕易于阅读。

### 5.5 时间轴文档自带英文

**情景**：TXT 末尾附带英文。

**处理**：**一律忽略**，以校对文档英文为准。

### 5.6 中文条目有重复或空文本

**情景**：TXT 中第 8、9 条重复，或第 96 条无文本。

**处理**：中文部分照抄保留，英文部分对应生成，保持行数一致。

### 5.7 中文含屏蔽字或缩写

**情景**：中文中出现 `SW`、`gld`、`Z好`、`D场`、`*渡` 等。

**处理**：照抄不改，英文按语义正常翻译或保留原文。

## 九、常见问题解答

**Q1：如果 TXT 自带英文与 DOCX 不一致怎么办？**
A：以 DOCX 为准，TXT 自带英文一律忽略。

**Q2：如果中文条目有重复或空文本怎么办？**
A：中文部分照抄保留，英文部分对应生成，保持行数一致。

**Q3：英文断句是否可以与中文不完全一致？**
A：行数必须一致，但断点位置可以根据英语语法适当调整，确保英文可读性。

**Q4：如果遇到专业术语或特殊名称怎么办？**
A：保持原文不变，确保专业术语的准确性和一致性。

**Q5：如果校对文档中有 `{.mark}` 标记怎么办？**
A：忽略标记，只取标记内的文字内容。

**Q6：如果中文含屏蔽字或缩写怎么办？**
A：照抄不改，英文按语义正常翻译或保留原文。

**Q7：如果时间轴文档中英文部分时间轴乱序怎么办？**
A：中文部分照抄，英文部分跟随对应中文的时间轴。
